# Idea 2: Permissionless Onchain GPU Rental Market

## Core Problem

GPU rental prices for the same hardware can vary significantly between
providers, and there is no standard contract or transparent pricing.

In addition, SLA issues in GPU rental (downtime, performance degradation,
etc.) are usually resolved through trust in the platform, with no verifiable
mechanism in place.

## Proposed Direction

A system where:

- SLA terms are tracked onchain.
- Payments happen automatically based on those tracked SLA terms.
- Disputes are resolved without human intervention.
