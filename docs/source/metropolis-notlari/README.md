# Monad Metropolis Notları

42 İstanbul Blockchain Kulübü için derlendi. Monad Metropolis hackathon'u boyunca izlenen oturumlardan, sponsor yayınlarından ve resmi kaynak sayfasından çıkan notlar.

İki şekilde kullanılabilir:

- **Okumak için:** Sırayla git. İlk üç dosya herkes için, sonrası ne inşa ettiğine göre değişir.
- **AI'ına vermek için:** İlgili dosyayı (ya da tüm klasörü) coding agent'ının bağlamına ekle. Nasıl yapılacağı `04-ai-ile-gelistirme.md` dosyasının sonunda.

## Bilmen gerekenler

- Ödül tutarları ve bounty listesi Eylül 2026'da platformdan alındı. Gönderim yapmadan önce güncel halini platformdan kontrol et.
- Konuşmacıların sözleri İngilizce orijinalinden alıntılandı; açıklamalar notu tutan kişinin yorumu.
- Türkçe dosyalarda teknik terimler (bounty, track, onboarding, indexer vb.) çevrilmeden bırakıldı. Dokümanlarda ve sponsor kanallarında bu isimlerle karşılaşacaksın.
